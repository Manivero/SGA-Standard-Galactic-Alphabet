# Шрифт Fairfax HD — атрибуция

Файл `FairfaxHD.ttf` в этой папке **не нарисован для проекта SGA** — это
готовый сторонний шрифт, включённый сюда по реальной открытой лицензии.

- **Авторское право:** Copyright (c) 2017-2020 Kreative Software

## Почему этот шрифт, а не нарисованный с нуля

Standard Galactic Alphabet — не изобретение Mojang/Minecraft. Это
конструированная письменность, созданная Tom Hall для серии Commander
Keen (1990), которую Mojang позже (2011) переиспользовал как шрифт
зачарований. Сам алфавит как набор форм букв официально закодирован в
Unicode Private Use Area под блоком **Standard Galactic** (U+EB40–U+EB5F)
реестром Under-ConScript Unicode Registry (UCSUR; см.
https://www.kreativekorp.com/ucsur/charts/sga.html, proposal автора
Rebecca Bettencourt, 2019-09-14).

Fairfax HD — это шрифт того же автора реестра, расширяющий покрытие
именно на этот зарегистрированный блок, выпущенный под OFL-1.1 — лицензией,
прямо разрешающей встраивание, модификацию и распространение совместно с
другим ПО (с условием не продавать сам шрифт отдельно и сохранять текст
лицензии). Это даёт SGA Programming Language легальный, рабочий рендеринг
рун зачарования без необходимости рисовать 26 глифов с нуля — и без
использования файлов, извлечённых из самой игры Minecraft (те являются
собственностью Mojang, "All rights reserved").

## Что нужно сделать пользователю, чтобы увидеть руны

VS Code не может тихо подключить шрифт из расширения как веб-страница
(`@font-face`) — редактор кода использует системные шрифты. Поэтому:

1. Установите `FairfaxHD.ttf` в системные шрифты (двойной клик на файле
   на Windows/macOS, или `cp` в `~/.local/share/fonts/` + `fc-cache -f` на Linux).
2. Расширение само выставит `"editor.fontFamily": "Fairfax HD"` для языка
   `.sga` через `contributes.configurationDefaults` в `package.json` — после
   установки шрифта в систему руны зачарования отобразятся автоматически.

Шрифт большой (~3 МБ), так как покрывает весь реестр UCSUR (десятки
конструированных алфавитов), а не только SGA — это и есть исходный файл
от автора, без модификаций.
